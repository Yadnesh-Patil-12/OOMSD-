## 📖 About This Repository

This repository contains academic assignments, presentations, and mini-project documentation prepared as part of the **Object-Oriented Modeling and System Design (OOMSD)** course during the B.Tech Computer Engineering program.

It includes seven practical assignments covering the subject coursework, along with a mini-project focused on a **Vehicle Repair Management System**.

The repository serves as a centralized collection of academic work, system design documentation, project reports, and presentations.

---

## 🎯 Objectives

- Understand object-oriented modeling concepts.
- Study system analysis and design methodologies.
- Understand the structure and behavior of software systems.
- Develop skills in modeling real-world systems.
- Learn to document software design and architecture.
- Apply object-oriented design concepts to practical problems.
- Prepare technical reports and project presentations.

## 🚗 Mini Project Overview

### Vehicle Repair Management System

The Vehicle Repair Management System is an academic mini-project focused on modeling and documenting a system for managing vehicle repair and service center activities.

**Key Areas of the Project:**

- Vehicle repair management.
- Vehicle service center operations.
- System modeling and design.
- Software requirement analysis.
- Object-oriented system representation.
- Technical project documentation.

**Project Objective:**

To study and design a structured management system for vehicle repair and service center operations using concepts of object-oriented modeling and system design.
